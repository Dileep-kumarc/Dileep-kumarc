### 🧠 Brain Tumor Detection — *The one I'm most proud of*
> **Stack:** Python · CNN · TensorFlow · Keras · OpenCV

Trained a Convolutional Neural Network on MRI scan datasets to classify brain tumor presence.

**Result:** `92%+ accuracy` — good enough to be submitted to Claude's Open Source Program.

**What I learned:** The moment a model crosses 90% accuracy on medical data, you understand why people dedicate careers to this.

### 💡 MemViz AI — *Kaggle Competition Build*

An app that visually explains how programming memory models work — built to make CS education more intuitive.

**What I learned:** Teaching through visualization forces you to truly understand what you're teaching.

### 📚 College Notes Gallery
